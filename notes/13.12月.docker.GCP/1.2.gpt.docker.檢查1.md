## 錯誤訊息:
docker 開啟後出現如下錯誤:
```
Virtualization support not detected
Docker Desktop failed to start because virtualization support was not detected. Please contact your IT administrator to enable virtualization or check system requirements.
```
未偵測到虛擬化支持
Docker Desktop 啟動失敗，因為未偵測到虛擬化支援。請聯絡您的 IT 管理員啟用虛擬化或檢查系統需求。





# gpt錯誤回復
在 **Windows** 上出現

> **Virtualization support not detected**
> 通常代表 **CPU 虛擬化未啟用、BIOS/UEFI 設定未開、或 Windows 功能未正確安裝**。以下依「實務最常見 → 進階」順序說明完整修正流程（適用 Docker Desktop）。

---

## 一、先確認 CPU 是否支援虛擬化（最重要）

### 方法 1：工作管理員

1. `Ctrl + Shift + Esc` → **效能**
2. 點 **CPU**
3. 右下角確認：

   * **Virtualization：Enabled** ✅
   * 若顯示 **Disabled / Not available** ❌ → 需進 BIOS

### 方法 2：指令確認

```cmd
systeminfo
```

查看：

```
Hyper-V Requirements:
    VM Monitor Mode Extensions: Yes
    Virtualization Enabled In Firmware: Yes
```

---

## 二、進 BIOS / UEFI 開啟虛擬化（90% 問題在這）

### 常見設定位置

* **Intel CPU** → `Intel Virtualization Technology (VT-x)`
* **AMD CPU** → `SVM Mode`

### 操作步驟

1. **重新開機**
2. 開機時連按：

   * `DEL` / `F2` / `F10` / `ESC`（依主機板）
3. 進入 BIOS → 找：

   * `Advanced`
   * `Advanced BIOS Features`
   * `Advanced CPU Configuration`
4. 設定：

   ```
   Intel Virtualization Technology → Enabled
   或
   SVM Mode → Enabled
   ```
5. `F10` → Save & Exit

🔔 **注意**：改完一定要「完全關機 → 再開機」

---

## 三、啟用 Windows 必要功能（Docker Desktop 必須）

Docker Desktop 依版本使用 **WSL2 或 Hyper-V**

### 方式 A：控制台（推薦）

1. `Win + R` → `optionalfeatures`
2. 勾選以下（至少）：

   * ✅ **Windows Hypervisor Platform**
   * ✅ **Virtual Machine Platform**
   * ✅ **Windows Subsystem for Linux**
   * （可選）Hyper-V（Pro / Enterprise 才有）
3. **重新開機**

---

## 四、確認 WSL2 正常（Docker 預設）

```cmd
wsl --status
```

應看到：

```
Default Version: 2
```

若不是：

```cmd
wsl --set-default-version 2
```

更新 WSL：

```cmd
wsl --update
```

---

## 五、BIOS 已開但仍錯誤 → 檢查衝突軟體

以下軟體 **會佔用虛擬化**，導致 Docker 啟動失敗：

### 常見衝突

| 軟體                 | 處理方式         |
| ------------------ | ------------ |
| VirtualBox（舊版）     | 升級至 6.1+ 或移除 |
| VMware Workstation | 停用或更新        |
| BlueStacks / 模擬器   | 關閉           |
| 某些防毒（特別是企業版）       | 關閉核心隔離       |

---

## 六、關閉 Windows「核心隔離」（部分電腦需要）

1. **Windows 安全性**
2. 裝置安全性 → **核心隔離**
3. 關閉 **Memory Integrity**
4. 重新開機

---

## 七、公司電腦 / 筆電的特殊情況

若是公司電腦：

* BIOS 被 **鎖定**
* 群組原則禁用虛擬化
* 不允許 Hyper-V / WSL

👉 **只能請 IT 開啟，使用者無法自行解**

---

## 八、快速檢查清單（懶人版）

✅ CPU 支援 VT-x / SVM
✅ BIOS 開啟虛擬化
✅ Windows 功能啟用（WSL / VM Platform）
✅ WSL2 預設
✅ 無其他虛擬機搶資源
✅ 完整重開機
