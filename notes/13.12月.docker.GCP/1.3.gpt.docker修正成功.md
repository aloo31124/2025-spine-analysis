## 🎯 真正的兇手（100% 命中）

### 👉 Windows 11 24H2（Build 26200） + VBS / 核心安全策略 BUG

你這一行是**關鍵證據**：

```text
虛擬化型安全性: 狀態: 未啟用
App Control for Business policy: 強制
```

👉 **即使 VBS 顯示未啟用，App Control for Business 仍在「強制模式」**
👉 這會 **直接阻斷 WSL2 / Hyper-V 的 VM 啟動**

這是 **Win11 新版已知問題**，不是你設定錯。

## ✅ 正確修正方式（請完全照順序）

---

### 【步驟 1】關閉「核心隔離（一定要做）」

1. 開啟 **Windows 安全性**
2. **裝置安全性**
3. 點 **核心隔離詳細資料**
4. 關閉：

   * ❌ **記憶體完整性（Memory integrity）**
5. **重新開機**

> ⚠️ 就算你看到是「關」，也請「打開 → 重開 → 再關 → 重開」

---

### 【步驟 2】關閉 VBS（真正關鍵）

以 **系統管理員** 開啟 CMD，執行：

```cmd
bcdedit /set hypervisorlaunchtype auto
```

然後：

```cmd
bcdedit /set vsmlaunchtype off
```

完成後 **重新開機**

---

### 【步驟 3】強制重新安裝 WSL VM Platform

以 **系統管理員 CMD** 執行：

```cmd
dism.exe /online /disable-feature /featurename:VirtualMachinePlatform /norestart
dism.exe /online /disable-feature /featurename:Microsoft-Windows-Subsystem-Linux /norestart
```

👉 重開機

再執行：

```cmd
dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart
dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
```

👉 **再重開機**

---

### 【步驟 4】更新並驗證 WSL

```cmd
wsl --update
wsl --set-default-version 2
wsl --status
```

#### 正確結果應為：

```
Default Version: 2
Kernel version: x.x.x
```

### 【步驟 5】Docker Desktop 設定（重要）

1. 開 Docker Desktop
2. Settings → General
3. 確認：

   * ✅ Use WSL 2 based engine
4. Settings → Resources → WSL Integration

   * 開啟你要用的 distro（或 default）
