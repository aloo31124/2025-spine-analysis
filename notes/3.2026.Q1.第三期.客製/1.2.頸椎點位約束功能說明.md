# 頸椎點位約束功能說明

## 功能概述
本功能為頸椎分析頁面新增了第六個點位，並實現了點位之間的聯動約束邏輯，以提高分析的準確性和便利性。

## 新增點位

### 原有點位（5個）
1. **點1**：頂部點（初始位置：30%, 10%）
2. **點2**：頸椎基準點（初始位置：35%, 20%）
3. **點3**：腰椎點（初始位置：35%, 30%）
4. **點4**：左下點（初始位置：30%, 41%）
5. **點5**：右下點（初始位置：24%, 52%）

### 新增點位
6. **點6**：頸椎參考點（初始位置：45%, 20%）
   - 位於點2的右側
   - 與點2保持平行關係（Y座標相同）

## 點位約束關係

### 1. 頸椎約束（點2 ↔ 點6）

#### 約束規則
- **平行關係**：點6在點2右邊並保持水平平行
- **上下移動**：當移動點2或點6的Y座標時，兩點會同步移動
  - 拖曳點2上下 → 點6跟隨上下移動
  - 拖曳點6上下 → 點2跟隨上下移動
- **左右移動**：當移動點2或點6的X座標時，兩點各自獨立移動
  - 拖曳點2左右 → 只有點2移動
  - 拖曳點6左右 → 只有點6移動

#### 應用場景
此約束確保頸椎分析時，兩個參考點始終保持在同一水平線上，避免因手動調整造成的誤差。

### 2. 腰椎約束（點2 ↔ 點3）

#### 約束規則
- **垂直關係**：點3與點2保持垂直對齊
- **左右移動**：當移動點2或點3的X座標時，兩點會同步移動
  - 拖曳點2左右 → 點3跟隨左右移動
  - 拖曳點3左右 → 點2跟隨左右移動
- **上下移動**：當移動點2或點3的Y座標時，兩點各自獨立移動
  - 拖曳點2上下 → 只有點2移動（注意：點6會跟隨）
  - 拖曳點3上下 → 只有點3移動

#### 應用場景
此約束確保腰椎分析時，兩個參考點始終保持在同一垂直線上，提高測量的準確性。

## 技術實現

### 核心檔案

#### 1. 工具函數檔案
- **檔案路徑**：`spine-client/src/utils/pointConstraints.js`
- **功能**：封裝所有點位約束相關的業務邏輯

#### 2. 主要函數說明

##### `applyPointConstraints(points, draggedPointIndex, newX, newY, previousPoint)`
應用點位拖曳約束，處理聯動邏輯。

**參數**：
- `points`：所有點位陣列
- `draggedPointIndex`：被拖曳的點位索引
- `newX`：新的X座標
- `newY`：新的Y座標
- `previousPoint`：拖曳前的點位資訊

**返回值**：更新後的所有點位陣列

**約束處理邏輯**：
```javascript
// 頸椎約束（點2和點6）
if (draggedPointIndex === 1) {  // 拖曳點2
    點6.y = newY;  // 點6跟隨Y軸移動
}
if (draggedPointIndex === 5) {  // 拖曳點6
    點2.y = newY;  // 點2跟隨Y軸移動
}

// 腰椎約束（點2和點3）
if (draggedPointIndex === 1) {  // 拖曳點2
    點3.x = newX;  // 點3跟隨X軸移動
}
if (draggedPointIndex === 2) {  // 拖曳點3
    點2.x = newX;  // 點2跟隨X軸移動
}
```

##### `initializePoints(containerWidth, containerHeight)`
初始化所有點位（含第六點位）。

**參數**：
- `containerWidth`：容器寬度
- `containerHeight`：容器高度

**返回值**：初始化的點位陣列

##### `initializePointsFromRelative(relativePoints, imageSize, containerWidth, containerHeight)`
從相對位置初始化點位（用於從拍照頁面接收數據）。

**參數**：
- `relativePoints`：相對位置陣列（0-1之間）
- `imageSize`：原始圖片尺寸 `{width, height}`
- `containerWidth`：容器寬度
- `containerHeight`：容器高度

**返回值**：轉換後的點位陣列

##### `validatePointConstraints(points)`
驗證點位約束是否正確應用。

**參數**：
- `points`：點位陣列

**返回值**：驗證結果 `{isValid, errors}`

**驗證項目**：
- 點2和點6的Y座標是否相同（誤差容許 0.1px）
- 點2和點3的X座標是否相同（誤差容許 0.1px）

##### `getPointName(index)`
獲取點位名稱（用於顯示）。

**參數**：
- `index`：點位索引

**返回值**：點位名稱（繁體中文）

## 使用方式

### 在 AnalysisSpine.jsx 中使用

1. **匯入工具函數**：
```javascript
import { 
    applyPointConstraints, 
    initializePoints, 
    initializePointsFromRelative,
    getPointName,
    validatePointConstraints 
} from '../../utils/pointConstraints';
```

2. **初始化點位**：
```javascript
const initPoints = () => {
    const container = neckContainerRef.current;
    if (!container) return;

    const newPoints = initializePoints(
        container.offsetWidth, 
        container.offsetHeight
    );
    
    setPoints(newPoints);
};
```

3. **在拖曳事件中應用約束**：
```javascript
const handleMouseMove = (e) => {
    if (!isDragging) return;
    
    // ... 計算新座標 ...
    
    setPoints(prevPoints => {
        const previousPoint = prevPoints[currentPointIndex];
        
        // 應用點位約束（處理聯動邏輯）
        const updatedPoints = applyPointConstraints(
            prevPoints,
            currentPointIndex,
            newX,
            newY,
            previousPoint
        );
        
        return updatedPoints;
    });
};
```

## 測試方式

### 測試頸椎約束（點2 ↔ 點6）

1. **測試上下移動同步**：
   - 拖曳點2上下移動
   - 確認點6跟隨點2上下移動，Y座標始終相同
   - 拖曳點6上下移動
   - 確認點2跟隨點6上下移動，Y座標始終相同

2. **測試左右移動獨立**：
   - 拖曳點2左右移動
   - 確認點6不跟隨左右移動
   - 拖曳點6左右移動
   - 確認點2不跟隨左右移動

### 測試腰椎約束（點2 ↔ 點3）

1. **測試左右移動同步**：
   - 拖曳點2左右移動
   - 確認點3跟隨點2左右移動，X座標始終相同
   - 拖曳點3左右移動
   - 確認點2跟隨點3左右移動，X座標始終相同

2. **測試上下移動獨立**：
   - 拖曳點2上下移動
   - 確認點3不跟隨上下移動（但點6會跟隨）
   - 拖曳點3上下移動
   - 確認點2不跟隨上下移動

### 使用驗證函數

```javascript
// 在拖曳結束後驗證約束
const handleMouseUp = () => {
    setIsDragging(false);
    
    // 驗證點位約束
    const validation = validatePointConstraints(points);
    if (!validation.isValid) {
        console.warn('點位約束驗證失敗：', validation.errors);
    }
};
```

## 注意事項

1. **約束優先級**：當點2同時受到多個約束影響時（例如同時被點3和點6約束），所有約束都會正確執行。

2. **性能考量**：約束邏輯在每次拖曳移動時都會執行，已優化為O(1)時間複雜度。

3. **兼容性**：新增的第六點位與原有的計算邏輯完全兼容，不會影響現有功能。

4. **錯誤處理**：如果點位索引超出範圍，約束函數會安全地跳過，不會拋出錯誤。
