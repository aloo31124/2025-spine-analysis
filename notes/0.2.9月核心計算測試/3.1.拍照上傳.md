## 法1:失敗.手機無法觸發

使用 html, css, js 開發,
一個 RWD 的網站可在 電腦與手機上之瀏覽器運行,
有兩個按鈕分別為 [拍攝照片] 與 [上傳照片],
若在電腦上:
- [拍攝照片] 可呼叫 windows 或 mac 鏡頭功能。
- [上傳照片] 瀏覽器 會跳出視窗選取 電腦 圖片。
若在手機上:
- [拍攝照片] 可呼叫 手機 鏡頭功能。
- [上傳照片] 則會選取手機圖片。
[拍攝照片] 後, 會先進入編輯畫面, 可裁切, 若按下 [上傳照片], 
則儲存圖片,
最終 [上傳照片] 後, 網頁畫面垂直,水平置中會顯示拍攝(或上傳)照片。



## 法2

使用 html, css, js 開發,
一個 RWD的網站可在 手機上運行,
手機以 chrom 開啟該網站,
網站上有一個按鈕為 [拍攝照片], 
按下 [拍攝照片] 後, chrom 會觸發手機拍攝照片功能。
拍攝後可上傳照片並顯示於網頁畫面中
