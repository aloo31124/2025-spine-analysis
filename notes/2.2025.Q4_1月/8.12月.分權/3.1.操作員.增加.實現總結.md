# 操作員功能實現總結

## 📋 需求概述

新增「操作員」(Operator) 角色，具有以下特性：
- 需綁定店長
- 僅可增刪改商品，無其他權限
- 操作員創建商品時，商品所有者(userId)為店長，創建者(createId)為操作員
- 無營收和庫存檢視權限
- 白名單權限：拍照上傳、頸部分析、尾椎分析、客戶管理、枕頭商品、床墊管理

**文件**:

✅ 更新 `addProductPillow()` 和 `addProductMattress()` 方法：

```javascript
// 檢查是否為操作員
const isOperator = await storeManagerToOperatorService.isOperator(productPillow.userId);

if (isOperator) {
    // 取得綁定的店長ID
    const storeManagerId = await storeManagerToOperatorService.getStoreManagerIdByOperatorId(productPillow.userId);
    
    // 保存操作員ID作為 createId（實際創建者）
    const createId = productPillow.userId;
    
    // 將商品的 userId 設置為店長ID（商品所屬者）
    return ProductPillow.addProductPillow({
        ...productPillow,
        userId: storeManagerId,
        createId: createId
    });
}
```

**邏輯說明**：
- 操作員創建商品時，`userId` 綁定店長（商品所有者）
- `createId` 記錄操作員 ID（實際創建者）
- 非操作員正常創建商品

## 🔧 技術實現細節

### 權限驗證流程

1. **JWT Token 驗證**
   ```javascript
   const payload = authService.verifyJwt(req);
   const userId = payload?.userId;
   ```

2. **店長權限檢查**
   ```javascript
   const isStoreManager = await userToRoleService.isStoreManager(userId);
   if (!isStoreManager) {
       return res.status(403).json({ error: '權限不足' });
   }
   ```

3. **操作員身份檢查**
   ```javascript
   const isOperator = await storeManagerToOperatorService.isOperator(userId);
   ```

### 數據綁定關係

```
User (用戶表)
  ├─ UserToRole (用戶角色表)
  │    ├─ Admin (管理員)
  │    ├─ StoreManager (店長)
  │    └─ Operator (操作員)
  │
  └─ StoreManagerToOperator (店長綁定操作員表)
       ├─ storeManagerId (店長 userId)
       └─ operatorId (操作員 userId)

Product (商品表)
  ├─ userId (商品所有者 - 店長)
  └─ createId (實際創建者 - 操作員)
```

### 錯誤處理

- ✅ "操作員不存在User表中" - 404
- ✅ "該使用者已被其他角色綁定" - 409
- ✅ "權限不足" - 403
- ✅ "未授權" - 401
- ✅ "操作員未綁定店長" - 500

## 📝 使用流程

### 店長新增操作員
1. 店長登入系統
2. 點擊左選單「操作員設定」
3. 輸入操作員的 email
4. 點擊「新增操作員」
5. 系統檢查：
   - 該 email 是否存在於 User 表
   - 該用戶是否已被其他角色綁定
6. 新增成功後，在操作員列表中顯示

### 店長移除操作員
1. 在操作員列表中找到要移除的操作員
2. 點擊「移除」按鈕
3. 確認移除
4. 系統自動刪除：
   - UserToRole 表中的 Operator 角色
   - StoreManagerToOperator 表中的綁定關係

### 操作員創建商品
1. 操作員登入系統
2. 進入「枕頭商品」或「床墊管理」
3. 點擊「新增」
4. 填寫商品資訊
5. 點擊「儲存」
6. 系統自動：
   - 設定 `userId` 為店長 ID（商品所有者）
   - 設定 `createId` 為操作員 ID（實際創建者）
