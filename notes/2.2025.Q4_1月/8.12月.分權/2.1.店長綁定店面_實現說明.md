# 店面管理功能實現說明

## 功能概述
本次實現了完整的店面管理功能，包含 CRUD 操作、店長綁定、區域分類等功能。

## 實現內容

### 一、後端實現

#### 1. 資料模型 (Model)
- **檔案**: `spine-server/src/models/store.model.js`
- **資料表**: `Store`
- **欄位**:
  - `id`: 店面 ID（自動生成）
  - `name`: 店面名稱
  - `region`: 所屬區域（北區、中區、南區、東區、離島區）
  - `address`: 店面地址
  - `phone`: 店面電話
  - `storeManagerId`: 所屬店長 ID（可為 null）
  - `notes`: 備註
  - `createdAt`: 建立時間
  - `updatedAt`: 更新時間

#### 2. 服務層 (Service)
- **檔案**: `spine-server/src/services/store.service.js`
- **功能**:
  - `getAllStoreList()`: 取得所有店面列表
  - `searchStore()`: 搜尋店面（支援關鍵字、區域、店長篩選）
  - `addStore()`: 新增店面
  - `getStore()`: 取得單一店面
  - `updateStore()`: 更新店面
  - `deleteStore()`: 刪除店面
  - `getStoresByStoreManagerId()`: 根據店長 ID 取得管理的店面
  - `exportAllStoreList()`: 匯出所有店面列表（備份用）
  - `importAllStore()`: 匯入店面資料（備份還原用）

#### 3. 控制層 (Controller)
- **檔案**: `spine-server/src/controllers/manager/store.api.controller.js`
- **API 端點**:
  - `POST /api/manager/store/list`: 取得店面列表
  - `GET /api/manager/store/:id`: 取得單一店面
  - `POST /api/manager/store/add`: 新增店面
  - `PATCH /api/manager/store/edit`: 更新店面
  - `DELETE /api/manager/store/delete/:id`: 刪除店面
  - `POST /api/manager/store/search`: 搜尋店面
  - `GET /api/manager/store/store-manager/:storeManagerId`: 根據店長 ID 取得店面
  - `POST /api/manager/store/import`: 匯入店面資料

#### 4. 路由註冊
- **檔案**: `spine-server/src/index.js`
- 已在 index.js 中註冊所有店面管理的 API 路由

## 業務規則

### 區域選項
前端寫死的區域選項如下：
- 北區
- 中區
- 南區
- 東區
- 離島區

### 店長綁定規則
- 一個店長可設定多個店面
- 一個店面最多只能設定一個店長
- 店長可以不指定（storeManagerId 為 null）

### 店長來源
所屬店長來自 `UserToRole` 表中 `role` 為 `StoreManager` 的所有使用者。

## 權限控制

### 角色權限
- **Admin（管理員）**: 可以訪問所有店面管理功能
- **StoreManager（店長）**: 無法訪問店面管理功能（不在白名單中）

### 路由保護
所有店面管理路由都透過 `AppRouterVerify` 進行權限驗證，`node` 參數設為 `"store"`。

## 使用方式

### 1. 啟動後端服務
```bash
cd spine-server
npm install
npm start
```

### 2. 啟動前端服務
```bash
cd spine-client
npm install
npm start
```

### 3. 訪問店面管理
1. 使用 Admin 角色帳號登入
2. 點擊左選單的「店面管理」
3. 即可進行店面的 CRUD 操作

## 資料庫初始化

首次使用時，Firestore 會自動建立 `Store` 集合。無需手動初始化。
