### ask2.hostname:0.0.0.0
app.listen 為何 hostname 要改為 0.0.0.0? 能否使用 localhost 就好，分析其中差異

#### 回復
0.0.0.0 vs localhost 的差異分析
核心差異

綁定地址	              說明	                可存取來源
localhost / 127.0.0.1	  只監聽本機迴路介面	    僅限容器內部
0.0.0.0	                監聽所有網路介面	      容器內部 + 外部連線

#### 回復.說明圖
┌─────────────────────────────────────────────────────┐
│  Host Machine (你的電腦)                             │
│                                                     │
│   瀏覽器 ──► localhost:8080                         │
│                    │                                │
│                    ▼                                │
│   ┌─────────────────────────────────────┐          │
│   │  Docker Container                    │          │
│   │                                      │          │
│   │  如果綁定 127.0.0.1:                 │          │
│   │  ┌──────────────┐                   │          │
│   │  │ Node.js App  │ ◄─ 只接受容器內請求 │          │
│   │  │ 127.0.0.1    │   外部請求被拒絕 ✗  │          │
│   │  └──────────────┘                   │          │
│   │                                      │          │
│   │  如果綁定 0.0.0.0:                   │          │
│   │  ┌──────────────┐                   │          │
│   │  │ Node.js App  │ ◄─ 接受所有請求 ✓  │          │
│   │  │ 0.0.0.0      │                   │          │
│   │  └──────────────┘                   │          │
│   └─────────────────────────────────────┘          │
└─────────────────────────────────────────────────────┘
