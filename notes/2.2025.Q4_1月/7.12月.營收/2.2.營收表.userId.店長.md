## git commit
[feature] # [營收管理] 新增 [店長]userId 商品篩選功能。
[how]
- 修改 reportSpine.js 中 getProductPillowOptions 函數，新增 userId 參數以篩選商品。

[銷量折線圖]頁面
[text](../../spine-client/src/pages.spine/manager/ReportSpineSalesLineChart.jsx)

請依照 當前 userId 身分為 [店長]，來呈現其所屬的 商品營收/銷量 折線圖。
前端上述兩頁面，其 單個商品(全部商品)下拉選單，
在 productType 判斷後，還需要依照 當前 userId 來篩選 可選擇的商品。


後端 之 api 服務 也要做相應修改，
[text](../../spine-server/src/services/reportSpine.service.js)
[text](../../spine-server/src/models/reportSpine.model.js)

該服務中 已經從 token 中 取得 userId ，
該 userId 需先在 
[text](../../spine-server/src/services/userToRole.service.js)
新增判斷該 使用者 角色為 [店長] (StoreManager)。
若判斷非店長，請 return 文字: '權限不符'。
若為店長，
請先從兩張商品表: ProductPillow、ProductMattress 中， 
找出 該 userId 所屬的 兩種商品，
上述兩種商品在依序對應 
[客戶對應商品_枕頭]表 CustomerToProductPillow
[客戶對應商品_床墊]表 CustomerToProductMattress
來重新計算 營收/銷量 折線圖資料。
