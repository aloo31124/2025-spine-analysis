# [分析結果][新建客戶]流程實現總結

## 實現功能

在 AnalysisSpine.jsx 分析結束後，若選擇「新建客戶」，分析結果不會立即存入資料庫中的 CustomerAnalysisResult 表內，而是：

1. 先進入創建客戶的頁面 CustomerAddPage.jsx
2. 共用的子元件 CreateEditCustomer.jsx 內使用 AnalysisResult.jsx 展示當前的分析結果
3. 客戶儲存後，再將該分析結果與 userId 存入 CustomerAnalysisResult 表

## 修改的文件

### 1. AnalysisSpine.jsx
- **修改功能**: `handleCreateNewCustomer()`
- **變更內容**: 
  - 不再直接保存分析結果到資料庫
  - 將分析結果資料暫時保存到 localStorage 中的 `pendingAnalysisData` 
  - 包含所有必要的分析資料：points, lines, intersectionPoints, calculationResults, backgroundImage 等

### 2. CustomerAddPage.jsx  
- **新增功能**: 
  - 從 localStorage 讀取暫存的分析結果並顯示
  - 在創建客戶成功後，將分析結果與新客戶 ID 一起保存到資料庫
- **修改功能**:
  - `useEffect`: 改為從 localStorage 讀取暫存資料
  - `handleAddCustomer()`: 新增保存分析結果的邏輯
  - `handleRefreshAnalysisResults()`: 更新為處理暫存資料

### 3. AnalysisResult.jsx
- **修改功能**: `handleDeleteResult()`
- **變更內容**: 
  - 支援刪除暫存的分析結果（沒有 id 的情況）
  - 對於暫存資料，直接從 localStorage 清除

### 4. customerAnalysisResult.js (API)
- **新增功能**:
  - `getPendingAnalysisData()`: 從 localStorage 獲取暫存分析結果
  - `clearPendingAnalysisData()`: 清除暫存分析結果  
  - `savePendingAnalysisData()`: 保存暫存分析結果

## 資料流程

1. **分析階段**: 
   - 用戶在 AnalysisSpine.jsx 完成圖像分析
   - 點擊「儲存結果」→「新建客戶」

2. **暫存階段**:
   - 分析結果暫存到 localStorage (`pendingAnalysisData`)
   - 跳轉到 CustomerAddPage.jsx

3. **展示階段**:
   - CustomerAddPage.jsx 讀取暫存資料
   - 通過 CreateEditCustomer.jsx → AnalysisResult.jsx 展示分析結果

4. **保存階段**:
   - 用戶填寫客戶資訊並點擊「新增」
   - 先保存客戶資料到資料庫
   - 成功後將分析結果與新客戶 ID 一起保存到 CustomerAnalysisResult 表
   - 清除 localStorage 中的暫存資料

## 後端配合

現有的 customerAnalysisResult.controller.js 已經支援：
- `addCustomerAnalysisResult`: 新增客戶分析結果
- 接收的資料包含：customerId, userId, analysisType, analysisData, points, lines, intersectionPoints, calculationResults, backgroundImage

## 測試要點

1. 分析完成後選擇「新建客戶」能正確跳轉
2. 在新建客戶頁面能看到分析結果預覽
3. 創建客戶成功後分析結果能正確保存到資料庫
4. localStorage 資料能正確清理
5. 刪除暫存分析結果功能正常

## 技術特點

- **無資料庫冗餘**: 只有在客戶創建成功後才將分析結果存入資料庫
- **良好的用戶體驗**: 用戶可以在創建客戶前預覽分析結果
- **錯誤處理**: 即使分析結果保存失敗，客戶創建也不會受影響
- **資料一致性**: 分析結果與客戶 ID 正確關聯
