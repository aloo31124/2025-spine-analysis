如下 node.js 框架於 firestore 進行商品搜尋, 
請使用 Fuse.js 第三方庫, 讓關鍵字 name 與 Product表name欄位進行相似搜尋

const db = require('../firestore');
exports.searchProduct = async (searchParam) => {
    const { name, state, createDate, type, priceMin, priceMax } = searchParam;
    let query = db.collection('Product');

    if (name) {
        // 使用 includes 進行模糊搜尋
        query = query.where('name', '==', new RegExp(name, 'i')); // gemini 方法 可使用
    }
    if (state) {
        query = query.where('state', '==', state);
    }
    if (createDate) {
        query = query.where('createDate', '==', createDate);
    }
    if (type) {
        query = query.where('type', '==', type);
    }
    if (priceMin) {
        query = query.where('price', '>=', Number.parseInt(priceMin));
    }
    if (priceMax) {
        query = query.where('price', '<=', Number.parseInt(priceMax));
    }

    const snapshot = await query.get();
    const searchResult = [];
    snapshot.forEach(doc => {
        searchResult.push({ id: doc.id, ...data });
    });

    return searchResult;
}

並可與 firestore 整合使用, 條列式精要列出, 並說明優缺點與使用情境。

---------------------------------------

以下是 **常用於中文字相似搜尋** 並可與 Firestore 整合的 **Node.js 第三方庫**：  

### **1. [Fuse.js](https://fusejs.io/)（🔥推薦）**  
**✅ 優勢**：  
- 支援 **模糊匹配、拼音、錯別字容錯**  
- 可在 **前端或後端** 使用，無需額外索引  

**❌ 缺點**：  
- 需在 **本地** 儲存數據，適合小規模數據  

**📌 適用情境**：  
- **Firestore 取出資料後**，使用 Fuse.js 進行本地搜尋  

**📝 使用方式**：  
```javascript
const Fuse = require('fuse.js');
const fuse = new Fuse(products, { keys: ['name'], threshold: 0.3 });
const result = fuse.search('苹果');
```

---

### **2. [Lunr.js](https://lunrjs.com/)**  
**✅ 優勢**：  
- 無需外部服務，支援 **全文檢索**  
- 適合 **離線模式或內存搜尋**  

**❌ 缺點**：  
- **不支援拼音**，且需先構建索引  

**📌 適用情境**：  
- 需 **本地快速檢索 Firestore 取出的資料**  

---

### **3. [pinyin-match](https://www.npmjs.com/package/pinyin-match)**  
**✅ 優勢**：  
- **拼音搜尋支援**（如 `"zhongguo"` 可匹配 `"中国"`）  
- 適合 **中文模糊匹配**  

**❌ 缺點**：  
- **不支援全文檢索**，僅適合小規模數據  

**📌 適用情境**：  
- 需 **匹配拼音輸入與 Firestore 取出資料**  

---

### **4. [nodejieba](https://github.com/fukuball/jieba-js)（中文分詞）**  
**✅ 優勢**：  
- **可拆解中文字**，支援 **關鍵字搜尋**  
- 與 Firestore `array-contains` 搭配，提升查詢精度  

**❌ 缺點**：  
- **需預先分詞儲存**  

**📌 適用情境**：  
- **Firestore 存入拆詞後的 `keywords` 陣列**，使用 `.where('keywords', 'array-contains', keyword)` 查詢  

---

### **總結**
| 套件 | 特色 | 適用情境 | Firestore 整合 |
|------|------|--------|----------------|
| **Fuse.js** | 🔥 模糊匹配、拼音支援 | **本地搜索 Firestore 資料** | ✅ **Firestore 查詢後過濾** |
| **Lunr.js** | 本地全文檢索 | **內存搜索，適合小數據** | ❌ 需預先索引 |
| **pinyin-match** | **拼音匹配** | **拼音搜尋 Firestore 資料** | ✅ 適用於中文輸入法 |
| **nodejieba** | **中文斷詞** | **提升 Firestore `array-contains` 查詢準確度** | ✅ **適合大規模文本** |

📌 **推薦方案**：
- **小型 Firestore 搜尋** → `Fuse.js`
- **拼音模糊搜尋** → `pinyin-match`
- **提升 Firestore 中文查詢精度** → `nodejieba` + `array-contains`
