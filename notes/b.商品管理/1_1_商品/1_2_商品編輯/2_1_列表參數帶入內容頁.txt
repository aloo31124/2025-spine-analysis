# React 中傳遞商品資訊到編輯頁面的常見做法

以下是將完整商品資訊從 `ProductListPage` 傳遞到 `ProductEditPage` 的幾種常見方法：

## 方法1：使用路由狀態 (React Router state)

```jsx
// ProductListPage.jsx
const handleEditProduct = (product) => {
  navigate(`/manager/product/edit/${product.id}`, { state: { product } });
};

// ProductEditPage.jsx
import { useLocation } from 'react-router-dom';

function ProductEditPage() {
  const { state } = useLocation();
  const product = state?.product;
  
  // 使用 product 資料...
}
```

## 方法2：使用 URL 參數 + API 重新獲取

```jsx
// ProductListPage.jsx
const handleEditProduct = (productId) => {
  navigate(`/manager/product/edit/${productId}`);
};

// ProductEditPage.jsx
import { useParams } from 'react-router-dom';
import { useEffect, useState } from 'react';

function ProductEditPage() {
  const { id } = useParams();
  const [product, setProduct] = useState(null);
  
  useEffect(() => {
    const fetchProduct = async () => {
      const response = await fetch(`/api/products/${id}`);
      setProduct(await response.json());
    };
    fetchProduct();
  }, [id]);
  
  // 使用 product 資料...
}
```

## 推薦做法

**對於大多數情況，推薦使用方法1（路由狀態）**，因為：

1. **簡單直接**：不需要額外的狀態管理或 API 調用
2. **安全性**：資料不會暴露在 URL 中
3. **臨時性**：狀態只在導航期間有效，不會殘留
4. **完整性**：可以傳遞完整的物件結構

如果商品資料很大或需要持久化，可以考慮組合使用方法1和方法2（路由狀態 + API 備份）。

## 完整實現示例 (使用方法1)

```jsx
// ProductListPage.jsx
function ProductListPage() {
  const navigate = useNavigate();
  
  const handleEditProduct = (product) => {
    navigate(`/manager/product/edit/${product.id}`, {
      state: { product } // 傳遞完整商品物件
    });
  };

  return (
    <div>
      {productList.map((product) => (
        <TableRow 
          key={product.id}
          obj={product}
          onEdit={() => handleEditProduct(product)} // 傳遞完整商品
        />
      ))}
    </div>
  );
}

// ProductEditPage.jsx
import { useLocation } from 'react-router-dom';

function ProductEditPage() {
  const { state } = useLocation();
  const product = state?.product; // 獲取傳遞的商品資料

  if (!product) {
    return <div>商品資料載入失敗</div>;
  }

  return (
    <div>
      <h1>編輯商品: {product.name}</h1>
      {/* 其他編輯表單... */}
    </div>
  );
}
```
