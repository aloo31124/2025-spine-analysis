商品價格 input number, 在 clickAddProduct 函式, 
price 存入 db 為 string, 原因為何? 如何改為 number

---------------------------------------------

newshop-client\src\components\manager\CreateEdit\CreateEditProduct.jsx

function CreateEditProduct() {
    // 路由
    const navigate = useNavigate();
    // 商品相關屬性
    const [name, setName] = useState(null);
    const [state, setState] = useState("草稿");
    const [type, setType] = useState(null);
    const [price, setPrice] = useState(0);

    const clickAddProduct = async () => {
        const res = await addProduct({name, state, type, price});
        if(res.status === 200) {
            alert("商品新增成功");
            navigate('/manager/product/list');
        } else {
            alert("商品新增失敗");
        }
    }

    return (
        <div className={style.CreateEditProduct}>
            <div className={style.CreateEditProductContainer}>
                <h2>商品價格</h2>
                <div className={style.CreateEditProductRow}>
                    <input type="number" 
                        placeholder='商品價格'
                        value={price}
                        onChange={e => setPrice(e.target.value)}
                    />
                </div>
            </div>
        </div>
    );
} export default CreateEditProduct;




====================================================================================

### **📌 price 存入 DB 為 String 的原因**
在 `onChange` 事件中，`e.target.value` 會回傳 `string`，即使 `input` 的 `type="number"`。因此 `price` 的 `useState` 變數最終仍然是 `string`，導致 `addProduct({ name, state, type, price })` 時，`price` 以字串格式傳入。

---

### **✅ 解決方案：將 `price` 轉換為 `number`**
1. **使用 `Number(e.target.value)` 確保 `price` 為數字**
2. **或使用 `parseFloat(e.target.value)` 來處理浮點數**
3. **確保 `clickAddProduct` 內 `price` 為數字**

---

### **🚀 修正後的程式碼**
```jsx
function CreateEditProduct() {
    const navigate = useNavigate();
    const [name, setName] = useState(null);
    const [state, setState] = useState("草稿");
    const [type, setType] = useState(null);
    const [price, setPrice] = useState(0);

    const clickAddProduct = async () => {
        const res = await addProduct({
            name, 
            state, 
            type, 
            price: Number(price) // ✅ 確保存入 DB 時為數字
        });
        if (res.status === 200) {
            alert("商品新增成功");
            navigate('/manager/product/list');
        } else {
            alert("商品新增失敗");
        }
    };

    return (
        <div className={style.CreateEditProduct}>
            <div className={style.CreateEditProductContainer}>
                <h2>商品價格</h2>
                <div className={style.CreateEditProductRow}>
                    <input 
                        type="number"
                        placeholder='商品價格'
                        value={price}
                        onChange={e => setPrice(Number(e.target.value))} // ✅ 在 onChange 轉換為數字
                    />
                </div>
            </div>
        </div>
    );
}

export default CreateEditProduct;
```

---

### **🎯 關鍵修正點**
✅ `onChange={e => setPrice(Number(e.target.value))}` → 確保 `price` 為數字  
✅ `clickAddProduct` 時 **再次轉換** `price: Number(price)`，避免 DB 接收到字串  

這樣 `price` 存入資料庫時就會是 `number` 格式 🎯🚀
