# 在 React 登入頁面添加密碼顯示/隱藏功能

以下是修改後的 `LoginPage.jsx`，添加了小眼睛圖標來切換密碼可見性：

```jsx
import React, { useRef, useState } from 'react';
import { useNavigate } from 'react-router-dom';
import { FaEye, FaEyeSlash } from 'react-icons/fa'; // 引入眼睛圖標

function LoginPage() {
    const navigate = useNavigate();
    const inputEMailRef = useRef('');
    const inputPasswordRef = useRef('');
    const [showPassword, setShowPassword] = useState(false); // 控制密碼顯示狀態

    /* 登入 */
    const clickLogin = async () => {
        // 登入邏輯...
    };

    /* 註冊 */
    const clickRegist = () => {
        navigate('/auth/regist/flow');
    };

    /* 忘記密碼 */
    const clickForgetPassword = () => {
        navigate('/auth/password/forget');
    };

    /* 切換密碼可見性 */
    const togglePasswordVisibility = () => {
        setShowPassword(!showPassword);
    };

    return (
        <div className='Form'>
            <h1>登入頁</h1>
            <input 
                type="text" 
                placeholder='信箱'
                ref={inputEMailRef} 
            />
            <div className="password-input-container">
                <input 
                    type={showPassword ? "text" : "password"} 
                    placeholder='密碼'
                    ref={inputPasswordRef} 
                />
                <span 
                    className="password-toggle-icon"
                    onClick={togglePasswordVisibility}
                >
                    {showPassword ? <FaEyeSlash /> : <FaEye />}
                </span>
            </div>
            <div className='btnBar'>
                <button onClick={clickLogin}>登入</button>
                <button onClick={clickForgetPassword}>忘記密碼</button>
            </div>
            <button onClick={clickRegist}>註冊</button>
        </div>
    );
}

export default LoginPage;
```

## 需要添加的 CSS 樣式

在你的 CSS 檔案中添加以下樣式：

```css
.password-input-container {
    position: relative;
    width: 100%;
}

.password-input-container input {
    width: 100%;
    padding-right: 30px; /* 為圖標留出空間 */
}

.password-toggle-icon {
    position: absolute;
    right: 10px;
    top: 50%;
    transform: translateY(-50%);
    cursor: pointer;
    color: #666;
}

.password-toggle-icon:hover {
    color: #333;
}
```

## 實現說明

1. **狀態管理**：
   - 使用 `useState` 來管理密碼是否顯示的狀態 (`showPassword`)
   - 預設狀態為 `false` (密碼隱藏)

2. **圖標切換**：
   - 使用 `react-icons` 庫中的 `FaEye` 和 `FaEyeSlash` 圖標
   - 根據 `showPassword` 狀態顯示不同的圖標

3. **輸入框類型切換**：
   - 根據 `showPassword` 狀態切換 `input` 的 `type` 屬性
   - `true` 時顯示為普通文字 (`type="text"`)
   - `false` 時顯示為密碼框 (`type="password"`)

4. **點擊事件**：
   - 點擊眼睛圖標時觸發 `togglePasswordVisibility` 函數
   - 該函數會切換 `showPassword` 的狀態

## 安裝依賴

如果你還沒有安裝 `react-icons`，需要先安裝：

```bash
npm install react-icons
# 或
yarn add react-icons
```

這個實現提供了良好的用戶體驗，讓用戶可以根據需要查看自己輸入的密碼，同時保持基本的安全性。
