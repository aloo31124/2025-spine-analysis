此種 nodemailer 使用 gamil服務送信的方式業界稱為何? 是否有其他方式?

這種使用 Gmail SMTP 服務寄送郵件的方式屬於「SMTP Relay」服務的一種。
    不過在企業環境中，通常會選擇專業的郵件發送服務，原因是 Gmail 有每日寄送限制，
    且可能面臨信件被標記為垃圾郵件的風險。
    其他常見的專業郵件服務包括：

專業郵件服務供應商（Email Service Provider, ESP）：
    Amazon SES（Simple Email Service）
    SendGrid
    Mailgun
    Mailchimp
    SparkPost


自建 SMTP 伺服器：
    使用自己的域名和伺服器
    完全控制但需要較多維護成本

專業郵件服務的優點：
    更高的寄送限制
    更好的寄送成功率
    提供詳細的分析報告
    更完善的垃圾郵件處理
    API 整合更方便
    提供郵件範本功能

請簡單扼要說明如下運作流程與機制:

const nodemailer = require('nodemailer');
const transporter = nodemailer.createTransport({
    service: 'gmail',
    auth: {
        user: process.env.Email_User,
        pass: process.env.Email_Password
    }
});
exports.sendMailVerifyCode = (mail) => {
    const mailOptions = {
        from: process.env.Email_User,
        to: 'aloo31124@gmail.com',
        subject: "新商城 - 信箱驗證碼",
        text: "您的驗證碼是: 123456",
    };
    transporter.sendMail(mailOptions, (error, info) => {
        if(error) return console.log("信件寄送失敗: ", error);
        console.log("信件寄送成功: ", info.response);
    });
}

### 運作流程與機制簡述：

1. **引入與初始化：**
   - 使用 `nodemailer` 模組處理郵件傳輸功能。
   - `createTransport` 方法建立郵件傳輸器 (`transporter`)，
        此處使用 Gmail 作為郵件服務提供者，
        並透過環境變數 (`process.env`) 提供驗證用的電子郵件帳號和密碼。

2. **信件選項設定：**
   - 在 `sendMailVerifyCode` 函數中，建立 `mailOptions` 物件，
    指定發件人 (`from`)、收件人 (`to`)、信件主旨 (`subject`)、以及信件內容 (`text`)。

3. **發送郵件：**
   - 呼叫 `transporter.sendMail` 方法，將 `mailOptions` 傳入，執行郵件寄送操作。
   - 若寄送失敗，執行錯誤回呼，記錄失敗原因；成功則輸出伺服器回應資訊。

### 核心機制：
- **SMTP（簡單郵件傳輸協定）：** 
  `nodemailer` 使用 SMTP 協議與 Gmail 伺服器溝通，完成郵件發送。
- **安全性：**
  使用 `auth` 提供的憑證驗證發送者身份，確保信件合法。
- **異步操作：**
  `sendMail` 方法採用回呼函數處理成功與失敗的非同步事件。
