你這段程式碼的錯誤在於：

```js
function RangeSlider(minDefault = 0, maxDefault = 200)
```

這是 JavaScript 的「函式預設參數」，**不適用於 React 元件的 props 傳遞方式**。

---

### 🔍 問題原因

React 傳遞 `props` 時，是透過物件結構（`props` object），而不是透過一般函式參數。因此這樣的寫法：

```js
function RangeSlider(minDefault = 0, maxDefault = 200)
```

會讓你拿到的是 `props.minDefault` 和 `props.maxDefault`，而不是直接變數。

所以：

* `minDefault` 和 `maxDefault` 會是 `undefined`，因為 React 傳入的是 `{ minDefault: 0, maxDefault: 200 }`，不是位置參數。
* 所以 `useState(minDefault)` 就變成 `useState(undefined)`，導致 `min` 為 `undefined`，UI 報錯。

---

### ✅ 正確寫法：從 `props` 解構，給預設值

```jsx
function RangeSlider({ minDefault = 0, maxDefault = 200 }) {
    const [min, setMin] = useState(minDefault);
    const [max, setMax] = useState(maxDefault);
    const [range, setRange] = useState([minDefault, maxDefault]); // 建議不要從 min / max 拿，否則是空值

    const handleMinChange = (e) => {
        const newMin = Number(e.target.value);
        setMin(newMin);
        setRange([newMin, range[1]]);
    };
    const handleMaxChange = (e) => {
        const newMax = Number(e.target.value);
        setMax(newMax);
        setRange([range[0], newMax]);
    };
    const handleRangeChange = (index, value) => {
        const newRange = [...range];
        newRange[index] = value;
        setRange(newRange);
        if (index === 0) setMin(value);
        else setMax(value);
    };

    return (
        <div className={style.rangeSlider}>
            <div className={style.inputGroup}>
                <input type="number" value={min} onChange={handleMinChange} />
                <span>~</span>
                <input type="number" value={max} onChange={handleMaxChange} />
            </div>
            <div className={style.sliderContainer}>
                <input
                    type="range"
                    min="0"
                    max={range[1] * 5}
                    value={range[0]}
                    onChange={(e) => handleRangeChange(0, Number(e.target.value))}
                />
                <input
                    type="range"
                    min="0"
                    max={range[1] * 5}
                    value={range[1]}
                    onChange={(e) => handleRangeChange(1, Number(e.target.value))}
                />
            </div>
        </div>
    );
}
export default RangeSlider;
```

---

### 📘 延伸說明

在 React 中，元件接受 `props` 的正確方式是：

```jsx
function MyComponent({ prop1 = default1, prop2 = default2 }) { ... }
```

而不是這樣寫：

```jsx
function MyComponent(prop1 = default1, prop2 = default2) { // ❌ 錯誤
```
