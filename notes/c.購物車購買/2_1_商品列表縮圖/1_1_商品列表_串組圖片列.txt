# 問題分析與修正方案

## 問題原因

在 `product.service.js` 中，`productList.map` 內使用了 `async/await`，但 `map` 會直接返回一個 Promise 陣列，而不是等待所有 Promise 解析後的結果。這就是為什麼你只看到 Promise 物件而不是實際數據。

## 錯誤修正方案

### 修正版本 1：使用 `Promise.all`

```javascript
exports.getProductList = async () => {
    try {
        console.log("[getProductList] start :");
        const productList = await Product.getAllProductList();
        
        // 使用 Promise.all 等待所有圖片請求完成
        const result = await Promise.all(
            productList.map(async product => {
                const imgList = await productImgFireStorage.getProductImgList(product.id);
                return {...product, imgList};
            })
        );
        
        console.log("[getProductList] end , result :", result);
        return result;
    } catch (error) {
        console.error("[getProductList] error :", error);
        throw error; // 建議將錯誤重新拋出，讓上層處理
    }
}
```

### 修正版本 2：使用 for...of 循環（更易於調試）

```javascript
exports.getProductList = async () => {
    try {
        console.log("[getProductList] start :");
        const productList = await Product.getAllProductList();
        const result = [];
        
        // 使用 for...of 逐一處理
        for (const product of productList) {
            const imgList = await productImgFireStorage.getProductImgList(product.id);
            result.push({...product, imgList});
        }
        
        console.log("[getProductList] end , result :", result);
        return result;
    } catch (error) {
        console.error("[getProductList] error :", error);
        throw error;
    }
}
```

## 關鍵修正點說明

1. **`map` 中的異步問題**：
   - 原代碼直接在 `map` 中使用 `async/await`，這會返回 Promise 陣列
   - 需要使用 `Promise.all` 來等待所有異步操作完成

2. **錯誤處理改進**：
   - 原代碼吞掉了錯誤（只有 console.error）
   - 修正後重新拋出錯誤，讓調用方能夠處理

3. **兩種風格的選擇**：
   - `Promise.all` 版本：並行請求，效率更高
   - `for...of` 版本：串行執行，更易於調試
