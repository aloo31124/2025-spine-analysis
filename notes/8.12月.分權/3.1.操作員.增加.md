#### [店長綁定操作員] api服務:
後端 api 服務，搜尋 [店面]邏輯如下:
storeManagerToOperator.js 攜帶 jwt token，
於 storeManagerToOperator.api.controller.js 取得 當前使用者 userId。

jwt token 取得 userId 方式可參考:
[text](../../spine-server/src/controllers/manager/product.api.controller.js)

並再取得 userId 後使用
[text](../../spine-server/src/services/userToRole.service.js)
判斷是否為 店長 (isStoreManager)，
若非 [店長]  return 文字 '權限不足'，
若是 [店長] 依照 userId (storeManagerId) 
於 storeManagerToOperator.service.js
處理後續操作。

若為 [新增操作員] 操作，
請先判斷該 meail 是否存在於 使用者表 (User) 中，
若不存在，回傳 文字 '操作員不存在User表中' 。
若存在，先於 userToRole 表判斷是否由其他角色綁定，
若已被綁定，回傳 文字 '該使用者已被其他角色綁定'。
若 userToRole 中無任何綁定角色，
則將該使用者 於 userToRole 表中新增角色 為 [操作員] (Operator)，
並於 storeManagerToOperator 表中新增 綁定資料。

反之，若為 [操作員設定]頁面中之 [刪除操作員] 操作，
則使用一樣之邏輯將 userToRole 、 storeManagerToOperator 表中將該綁定資料刪除。

[操作員設定]頁面中之 [操作員列表]，
也一樣使用上述邏輯，
依照 當前 [店長] userId (storeManagerId) 於
storeManagerToOperator 表中 取得 綁定的所有 [操作員]清單。
並顯示 操作員之 mail 與 userId 、帳號名稱 資料集合。
