### agent2.[營收折線圖]
左選單(MenuLeft.jsx) 選擇 [營收管理] 選項呈現
[營收折線圖] 頁面 ( ReportSpineRevenueLineChart.jsx )、
建立完整 後端api服務 與 前端頁面。

選擇 [營收折線圖] ( ReportSpineRevenueLineChart.jsx ) 頁面，
x軸為時間區間 (日、週、季、月)，取用 db表之 
CustomerToProductPillow 表 purchaseDate 欄位，
y軸為 營收總和，取用 db表之 
CustomerToProductPillow 表 price 欄位(每個 日、週、季、月) 總和。
若沒有營收資料則該時間單位之營收為0。

[營收折線圖] 頁面 有兩個篩選的下拉選單(切換篩選器):

- [切換篩選時間器] 可讓 x軸 時間區間 切換為 當前
    前10季、前18個月、前20週、前100天之時間區間。
    其使用 CustomerToProductPillow 表 purchaseDate 欄位。

- [切換篩選商品器] 可讓 y軸 營收總和 依照 商品名稱 切換。
    其使用 CustomerToProductPillow 表 productPillowId 欄位，
    productPillowId 對應 db表 ProductPillow 之 id 欄位，
    ProductPillow 表 name 欄位 為 商品名稱。

上述業務邏輯請盡量在後端 api 與服務實作完成，
(reportSpine.api.controller.js、reportSpine.service.js、reportSpine.model.js)
前端頁面( ReportSpineRevenueLineChart.jsx )
只負責呼叫 api (api\manager\reportSpine.js) 並統一使用 chart.js 繪製圖表。

請用繁體中文說明。
