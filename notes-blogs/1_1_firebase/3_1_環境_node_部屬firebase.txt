幾乎大改 node.js 結構...

1. 新增 scr 放入所有 mvc 程式碼

2. newshop-server\firebase.json
    {
        "functions": [
            {
                "source": ".", // -----------------------------------------> 路徑設定 src !!注意!
                "codebase": "default",
                "ignore": [
                    "node_modules",
                    ".git",
                    "firebase-debug.log",
                    "firebase-debug.*.log",
                    "*.local"
                ]
            }
        ]
    }


3. newshop-server\package.json
    {
        "name": "newshop-server",
        "main": "src/index.js", // ----------------------------------> 需 src目錄
        "scripts": {
            "deploy": "firebase deploy --only functions:api"
        },
        "engines": {
            "node": "22"
        },
        "dependencies": {
            ...
            "firebase-functions": "^6.2.0",  // ---------------------> 另外安裝
            ...
        }
    }


4. 上述設定好後, 
    > firebase deploy
