为了在开发环境和生产环境中动态切换 `BASE_URL`，可以通过以下几种方法来实现，推荐使用 **环境变量** 配合 Webpack 或 Vite 的构建工具设置不同环境的值。

---

### **方案：使用环境变量切换 BASE_URL**

#### **1. 设置环境变量**
在项目根目录下创建 `.env.development` 和 `.env.production` 文件：
- **`.env.development`** (开发环境)
  ```env
  REACT_APP_BASE_URL=http://localhost:8081/api/auth
  ```

- **`.env.production`** (生产环境)
  ```env
  REACT_APP_BASE_URL=https://your-production-url/api/auth
  ```

#### **2. 修改代码动态获取 `BASE_URL`**
在 `auth.js` 文件中使用 `process.env.REACT_APP_BASE_URL` 读取环境变量：
```javascript
import axios from 'axios';

const BASE_URL = process.env.REACT_APP_BASE_URL;

/* 送出註冊信箱 */
export const postMail = async (mail) => {
    return axios.post(`${BASE_URL}/regist/mail`, { mail });
};

/* 信箱新建使用者 */
export const postUser = async (mail) => {
    return axios.post(`${BASE_URL}/regist/user/add`, { mail });
};

/* 更新使用者註冊資訊 */
export const updateUser = async (newUser) => {
    return axios.post(`${BASE_URL}/regist/user/info`, { newUser });
};

/* 驗證註冊碼 */
export const verifyCode = async (newUser) => { ... };

/* 註冊更新密碼 */
export const updatePassword = async (newUser) => { ... };

/* 登入 */
export const login = async (account, password) => { ... };
```

---

### **3. 确保构建工具支持环境变量**
React 项目使用 `create-react-app` 创建时，默认支持读取 `.env` 文件，前缀需要为 `REACT_APP_`。  
部署时：
- **开发环境**：`npm start` 会读取 `.env.development`。
- **生产环境**：`npm run build` 会读取 `.env.production`。

---

### **4. 部署到 Firebase Hosting**
在 Firebase Hosting 中，确保构建时已打包正确的 `BASE_URL`。

1. **安装 Firebase CLI**：
   ```bash
   npm install -g firebase-tools
   ```

2. **初始化 Firebase 项目**：
   ```bash
   firebase init
   ```

3. **构建和部署**：
   - **构建生产版本**：
     ```bash
     npm run build
     ```
   - **部署到 Firebase Hosting**：
     ```bash
     firebase deploy
     ```

---

### **其他方式（次选方案）**
如果无法使用环境变量，也可以手动判断运行环境：
```javascript
const BASE_URL =
    process.env.NODE_ENV === 'production'
        ? 'https://your-production-url/api/auth'
        : 'http://localhost:8081/api/auth';
```

这种方式对小项目快速开发有效，但推荐使用 **环境变量**，可以更灵活地管理多个环境。
