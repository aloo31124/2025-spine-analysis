### **📌 React + Node.js 批次上傳檔案最佳實踐**
針對 **React 前端** 與 **Node.js 後端**，批次上傳檔案可透過以下方式實作：  

---

## **🚀 1. React 前端：推薦的第三方套件與方法**
### ✅ **推薦套件**
| **套件名稱**       | **用途** | **安裝指令** |
|------------------|----------------|-------------|
| **react-dropzone** | 拖拉上傳與多檔案選擇 | `npm install react-dropzone` |
| **axios** | 發送 `multipart/form-data` 格式請求 | `npm install axios` |
| **formik + yup** | 表單處理與驗證 | `npm install formik yup` |

### 📌 **React 多檔案上傳步驟**
1. 使用 `react-dropzone` 或 `input[type=file]` 來選擇檔案。
2. 將檔案轉為 `FormData` 格式，並使用 `axios` 傳送至 Node.js。
3. 顯示上傳進度條（可搭配 `axios` 的 `onUploadProgress`）。

### 📝 **React 批次上傳範例**
```jsx
import React, { useState } from "react";
import { useDropzone } from "react-dropzone";
import axios from "axios";

const FileUpload = () => {
  const [files, setFiles] = useState([]);

  const onDrop = (acceptedFiles) => {
    setFiles([...files, ...acceptedFiles]);
  };

  const uploadFiles = async () => {
    const formData = new FormData();
    files.forEach((file) => {
      formData.append("files", file);
    });

    await axios.post("http://localhost:5000/upload", formData, {
      headers: { "Content-Type": "multipart/form-data" },
      onUploadProgress: (progressEvent) => {
        console.log(`Upload Progress: ${Math.round((progressEvent.loaded * 100) / progressEvent.total)}%`);
      }
    });
  };

  return (
    <div>
      <div {...useDropzone({ onDrop })} style={{ border: "2px dashed #ddd", padding: "20px" }}>
        拖放檔案或點擊上傳
      </div>
      <button onClick={uploadFiles}>上傳</button>
    </div>
  );
};

export default FileUpload;
```

---

## **🌍 2. React 傳送至 Node.js 的格式**
- 應使用 **`multipart/form-data`**，因其專為上傳檔案設計。
- `FormData` 物件可將多個檔案一起傳送，後端可透過 `req.files` 解析。

---

## **🖥️ 3. Node.js 後端：推薦的第三方套件**
### ✅ **推薦套件**
| **套件名稱** | **用途** | **安裝指令** |
|--------------|--------------------|-------------|
| **multer** | 解析 `multipart/form-data`，處理上傳 | `npm install multer` |
| **fs-extra** | 方便管理檔案（搬移、刪除） | `npm install fs-extra` |

### 📌 **Node.js 接收批次上傳檔案範例**
```javascript
const express = require("express");
const multer = require("multer");
const path = require("path");
const fs = require("fs-extra");

const app = express();
const uploadDir = path.join(__dirname, "uploads");

// 確保目錄存在
fs.ensureDirSync(uploadDir);

const storage = multer.diskStorage({
  destination: (req, file, cb) => cb(null, uploadDir),
  filename: (req, file, cb) => cb(null, `${Date.now()}-${file.originalname}`)
});

const upload = multer({ storage });

app.post("/upload", upload.array("files", 10), (req, res) => {
  return res.json({ message: "檔案上傳成功", files: req.files });
});

app.listen(5000, () => console.log("Server running on port 5000"));
```
