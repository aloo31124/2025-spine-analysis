### ✅ **3. 文件傳輸時兩者關係**
| **比較項目**      |  **FormData**                  | **Base64** |
| **適用情境**      |  檔案上傳（大檔案）            | 小型檔案內嵌 |
| **傳輸格式**      |  `multipart/form-data`       | `text/plain`（Base64 字串） |
| **檔案大小影響**  |  無額外膨脹                    | 會增大約 33%     |
| **適合方式**      |  **前端 → 後端上傳檔案**       | **前端直接顯示圖片/文件內容** |

- **🔹 前端 → 後端上傳** → **使用 `FormData`**
- **🔹 小型圖示或內嵌內容** → **使用 `Base64`**
- **🔹 下載時可使用 Base64，但通常建議以 URL 提供檔案**  

結論：文件、影音等大檔案應 **優先使用 `FormData`**，Base64 只適合小型內嵌用途 🚀

### **📌 FormData 與 Base64 簡述與文件傳輸關係**  

### ✅ **1. FormData 簡述**
- **用途**：專門用來傳輸 **檔案（如圖片、影片、文件）**，並支援 **`multipart/form-data`** 格式。  
- **優勢**：適合大檔案上傳，直接傳送 `Blob` 或 `File`，不會影響檔案原始格式。  
- **範例（上傳文件）**：
  ```javascript
  const formData = new FormData();
  formData.append("file", file);
  axios.post("/upload", formData, { headers: { "Content-Type": "multipart/form-data" } });
  ```

---

### ✅ **2. Base64 簡述**
- **用途**：將 **二進位數據（如圖片、影片、文件）轉換成純文字字串**，適合內嵌於 JSON 或 HTML 內。  
- **優勢**：適用於小型檔案（如小圖示），可直接存於資料庫或前端渲染。  
- **缺點**：Base64 會使檔案大小膨脹 **約 33%**，不適合傳輸大檔案。  
- **範例（圖片轉 Base64）**：
  ```javascript
  const reader = new FileReader();
  reader.readAsDataURL(file);
  reader.onload = () => console.log(reader.result); // "data:image/png;base64,iVBORw0KGgoAAA..."
  ```

---

### ✅ **3. 文件傳輸時兩者關係**
| **比較項目**      | **FormData**                  | **Base64** |
|--------------|------------|-----------|
| **適用情境**      | 檔案上傳（大檔案）            | 小型檔案內嵌 |
| **傳輸格式**      | `multipart/form-data`       | `text/plain`（Base64 字串） |
| **檔案大小影響**  | 無額外膨脹                    | 會增大約 33%     |
| **適合方式**      | **前端 → 後端上傳檔案**       | **前端直接顯示圖片/文件內容** |

- **🔹 前端 → 後端上傳** → **使用 `FormData`**
- **🔹 小型圖示或內嵌內容** → **使用 `Base64`**
- **🔹 下載時可使用 Base64，但通常建議以 URL 提供檔案**  

結論：文件、影音等大檔案應 **優先使用 `FormData`**，Base64 只適合小型內嵌用途 🚀
