如下, node.js express, 使用 商品名稱 productId, 與 圖片名稱imgName ,
依照上述兩者參數, 將指定路徑圖片刪除, 並從 fireStore db 移除資料。

src\index.js
    app.delete('/api/manager/product/img/delete/...', productApiController.deleteProductImg);

src\controllers\manager\product.api.controller.js
    exports.deleteProductImg = async (req, res) => {}

src\services\product.service.js  
    exports.deleteProductImg = async () => {}


====================================================================================
----------------------------

你的需求是 **根據 `productId` 和 `imgName` 刪除指定圖片**，並同步刪除 Firestore 中的對應資料。  
這需要：
1. **從伺服器的 `C:/shopStorage/product/{productId}/{imgName}` 刪除圖片**
2. **從 Firestore `ProductImg` 表刪除對應的資料**
3. **提供 API 讓前端請求刪除**

---

## **📌 優化後的 `index.js`**
```javascript
app.delete('/api/manager/product/img/delete/:productId/:imgName', productApiController.deleteProductImg);
```

---

## **📌 優化後的 `product.api.controller.js`**
```javascript
const productService = require('../../services/product.service');

exports.deleteProductImg = async (req, res) => {
    try {
        const { productId, imgName } = req.params;

        if (!productId || !imgName) {
            return res.status(400).json({ result: '400', error: '缺少 productId 或 imgName' });
        }

        // 呼叫服務層刪除圖片
        await productService.deleteProductImg(productId, imgName);

        res.status(200).json({ result: '200', message: '圖片刪除成功' });
    } catch (error) {
        console.error(`[Delete Product Image Error] ${error.message}`);
        res.status(500).json({ result: '500', error: error.message });
    }
};
```

---

## **📌 優化後的 `product.service.js`**
```javascript
const fs = require('fs');
const path = require('path');
const { getFirestore } = require('firebase-admin/firestore');

const BASE_UPLOAD_DIR = 'C:/shopStorage/product';
const db = getFirestore();

exports.deleteProductImg = async (productId, imgName) => {
    try {
        const imagePath = path.join(BASE_UPLOAD_DIR, productId, imgName);

        // 1️⃣ **刪除本地端圖片**
        if (fs.existsSync(imagePath)) {
            fs.unlinkSync(imagePath);
            console.log(`圖片刪除成功: ${imagePath}`);
        } else {
            console.warn(`圖片不存在: ${imagePath}`);
        }

        // 2️⃣ **刪除 Firestore 資料**
        const productImgRef = db.collection('ProductImg');
        const snapshot = await productImgRef
            .where('productId', '==', productId)
            .where('imgName', '==', imgName)
            .get();

        if (snapshot.empty) {
            console.warn(`Firestore 無對應圖片資料: ${productId}/${imgName}`);
        } else {
            snapshot.forEach(doc => doc.ref.delete());
            console.log(`Firestore 資料刪除成功: ${productId}/${imgName}`);
        }

        return { success: true };
    } catch (error) {
        throw new Error(`刪除圖片失敗: ${error.message}`);
    }
};
```

## **📌 優化點**
✅ **刪除 `C:/shopStorage/product/{productId}/{imgName}` 的本地圖片**  
✅ **從 Firestore `ProductImg` 表中刪除對應資料**  
✅ **若圖片或資料不存在，不影響其他處理**  
✅ **可擴展支援更多圖片格式**  

🚀 **這樣就能讓 `productId` & `imgName` 指定圖片刪除，並同步更新 Firestore！** 🎉
