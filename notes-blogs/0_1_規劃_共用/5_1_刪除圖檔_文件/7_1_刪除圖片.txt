這裡的需求分為兩部分：  
1. **刪除 `C:/shopStorage/product/` 目錄下所有圖片**  
2. **清空資料庫 `ProductImg` 表的所有資料，但保留表結構**

---

### **📌 1️⃣ 後端 API 設計**
#### **🔹 `newshop-server/src/index.js`**
```javascript
app.delete('/api/manager/product/img/delete/all', productApiController.deleteProductImgAll);
```

---

### **📌 2️⃣ 控制器**
#### **🔹 `newshop-server/src/controllers/manager/product.api.controller.js`**
```javascript
const { deleteProductImgAll } = require('../../services/product.service');

exports.deleteProductImgAll = async (req, res) => {
    try {
        await deleteProductImgAll();
        res.status(200).json({ result: '200', message: '所有商品圖片已刪除' });
    } catch (error) {
        console.error(`[Delete Error] ${error.message}`);
        res.status(500).json({ result: '500', error: error.message });
    }
};
```

---

### **📌 3️⃣ 服務層**
#### **🔹 `newshop-server/src/services/product.service.js`**
```javascript
const fs = require('fs-extra');
const path = require('path');
const db = require('../models'); // 假設 Sequelize ORM

const PRODUCT_IMG_DIR = 'C:/shopStorage/product/';

exports.deleteProductImgAll = async () => {
    try {
        // **1️⃣ 刪除 product 資料夾下所有圖片**
        if (fs.existsSync(PRODUCT_IMG_DIR)) {
            await fs.emptyDir(PRODUCT_IMG_DIR); // 清空資料夾
            console.log('✅ 商品圖片資料夾已清空');
        }

        // **2️⃣ 清空 ProductImg 表**
        await db.ProductImg.destroy({ where: {} }); // 刪除所有資料，保留表
        console.log('✅ ProductImg 表資料已清空');
    } catch (error) {
        console.error(`[Delete Error] ${error.message}`);
        throw new Error('刪除商品圖片時發生錯誤');
    }
};
```
---
## **📌 4️⃣ 測試方式**
### **🔹 透過 Postman 或 CURL 測試 API**
```bash
curl -X DELETE http://localhost:5000/api/manager/product/img/delete/all
```
✅ 成功後，所有商品圖片將被刪除，且 `ProductImg` 資料表的數據清空，但表結構仍保留。  

---

## **📌 總結**
- **使用 `fs-extra.emptyDir()`** 刪除 `C:/shopStorage/product/` 目錄內的所有圖片  
- **使用 `Sequelize.destroy({ where: {} })`** 清空 `ProductImg` 表內的所有資料，但不刪除表  
- **保留錯誤處理，確保 API 穩定**  

這樣就完成了 **批量刪除商品圖片與清空資料庫的功能** 🚀
