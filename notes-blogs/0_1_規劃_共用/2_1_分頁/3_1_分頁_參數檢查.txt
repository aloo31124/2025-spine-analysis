你可以使用 `PropTypes` 來檢查 `pagingParam` 是否符合指定的格式，也可以手動檢查類型，避免參數錯誤影響功能。以下是優化後的 `PaginationBar.jsx`：  

### 優化點：
1. **使用 PropTypes** 檢查 `pagingParam` 是否符合 `{ pageIndex, pageSize, sort, pageTotal, dataTotal }` 格式。
2. **手動檢查** `pagingParam` 是否包含所有必要屬性，並確保數值類型正確。
3. **錯誤處理** 若 `pagingParam` 格式錯誤，則顯示警告並避免頁面崩潰。

---

### **優化後的 PaginationBar.jsx**
```jsx
import React from "react";
import PropTypes from "prop-types";

function PaginationBar({ pagingParam, clickPageChange }) {
    // 檢查 pagingParam 是否符合格式
    const isValidPagingParam =
        pagingParam &&
        typeof pagingParam.pageIndex === "number" &&
        typeof pagingParam.pageSize === "number" &&
        typeof pagingParam.pageTotal === "number" &&
        typeof pagingParam.dataTotal === "number" &&
        typeof pagingParam.sort === "string";

    if (!isValidPagingParam) {
        console.error("PaginationBar: pagingParam 格式錯誤", pagingParam);
        return <div className="pagination-error">分頁參數錯誤</div>;
    }

    // 處理頁碼切換
    const handlePageChange = (newPage) => {
        if (newPage < 1 || newPage > pagingParam.pageTotal) return;
        clickPageChange(newPage);
    };

    return (
        <div className="pagination">
            <button 
                onClick={() => handlePageChange(pagingParam.pageIndex - 1)} 
                disabled={pagingParam.pageIndex === 1}
            >
                上一頁
            </button>

            {[...Array(pagingParam.pageTotal)].map((_, index) => {
                const pageNum = index + 1;
                return (
                    <button
                        key={pageNum}
                        onClick={() => handlePageChange(pageNum)}
                        style={{
                            fontWeight: pagingParam.pageIndex === pageNum ? "bold" : "normal",
                            backgroundColor: pagingParam.pageIndex === pageNum ? "#333" : "#fff",
                            color: pagingParam.pageIndex === pageNum ? "#fff" : "#000",
                        }}
                    >
                        {pageNum}
                    </button>
                );
            })}

            <button 
                onClick={() => handlePageChange(pagingParam.pageIndex + 1)} 
                disabled={pagingParam.pageIndex === pagingParam.pageTotal}
            >
                下一頁
            </button>
        </div>
    );
}

// 定義 PropTypes 檢查
PaginationBar.propTypes = {
    pagingParam: PropTypes.shape({
        pageIndex: PropTypes.number.isRequired,
        pageSize: PropTypes.number.isRequired,
        pageTotal: PropTypes.number.isRequired,
        dataTotal: PropTypes.number.isRequired,
        sort: PropTypes.string.isRequired,
    }).isRequired,
    clickPageChange: PropTypes.func.isRequired,
};

export default PaginationBar;
```

---

### **優化後的特點**
✅ **自動檢查** `pagingParam` 格式，不符合時顯示錯誤訊息並避免頁面崩潰。  
✅ **上一頁/下一頁按鈕** 會根據 `pageIndex` 是否為首尾頁來 `disabled` 按鈕。  
✅ **當前頁面高亮**，可自訂顏色（目前黑底白字）。  
✅ **PropTypes 檢查**，確保 `pagingParam` 必須傳遞正確的值。  

這樣在 `ProductListPage.jsx` 引入 `PaginationBar` 時，能確保分頁參數正確，並提供更穩定的分頁功能！ 🚀
