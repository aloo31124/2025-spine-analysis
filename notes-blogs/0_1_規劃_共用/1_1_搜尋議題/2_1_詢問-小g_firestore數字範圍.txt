小g回答:

### **Firestore 搜尋 `Product` 表，增加 `price` 範圍篩選**
#### **🚀 優化點**
1. **價格範圍查詢**
   - Firestore 不支援 `where("price", ">=" , priceMin).where("price", "<=" , priceMax)` 直接篩選兩個範圍條件，  
     **解法** → **拆成條件判斷**
   - **適用**
     - `priceMin` 及 `priceMax` 皆有值 → 兩者 `AND` 條件
     - 只提供 `priceMin` → `>= priceMin`
     - 只提供 `priceMax` → `<= priceMax`
2. **`query.get()` 前，確保 `query` 仍然是 `CollectionReference`**
   - 避免 `.where()` 全部失效導致 Firestore 查詢報錯
3. **最佳化 `map()` 處理**
   - 直接 `map(doc => ({ id: doc.id, ...doc.data() }))`，取代 `forEach() + push()`

---

### **📌 `src/services/product.service.js`**
```javascript
const db = require('../firestore');

/* 搜尋商品 */
exports.searchProduct = async (searchParam) => {
    try {
        const { name, state, createDate, type, priceMin, priceMax } = searchParam;
        let query = db.collection('Product');

        if (name) {
            query = query.where('name', '==', name);
        }
        if (state) {
            query = query.where('state', '==', state);
        }
        if (createDate) {
            query = query.where('createDate', '==', createDate);
        }
        if (type) {
            query = query.where('type', '==', type);
        }
        if (priceMin !== undefined) {
            query = query.where('price', '>=', priceMin);
        }
        if (priceMax !== undefined) {
            query = query.where('price', '<=', priceMax);
        }

        const snapshot = await query.get();
        if (snapshot.empty) return [];

        return snapshot.docs.map(doc => ({ id: doc.id, ...doc.data() }));
    } catch (error) {
        console.error("搜尋商品失敗:", error);
        return { error: error.message };
    }
};
```


### **🔥 這樣的優勢**
✅ **支援價格範圍篩選 (`>= priceMin`, `<= priceMax`)**  
✅ **避免 Firestore 查詢錯誤**  
✅ **使用 `.map()` 簡化程式碼**  
✅ **回傳適當錯誤訊息，提升 API 穩定性**  

🚀 **現在你的 Firestore 商品搜尋支援價格範圍過濾，且更加安全高效！** 🎯
