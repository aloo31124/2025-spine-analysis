請依照 上述討論, 呈現一個對於 node.js express ,
完整明確的 models 範本, 操作db為 fireStore,
並可定義檢查欄位。

----------------------------

    以下是基於 **Node.js + Express**，使用 **Firebase Firestore** 進行資料存取的 **Model 範本**，並內建 **欄位檢查與驗證**：  

    ---

    ### 📌 **完整 Firestore Model 設計（包含欄位驗證）**  
    🔹 **使用 `zod` 來驗證資料格式**（比 `Joi` 更輕量且適合 TypeScript）。  
    🔹 **封裝 Firestore CRUD 操作**，避免直接在 Controller 操作資料庫。  

    ```javascript
    const { z } = require("zod"); // 引入 zod 進行欄位驗證
    const { db } = require("../config/firebase"); // 連接 Firestore

    // 🔹 1️⃣ 定義 User Schema（欄位驗證）
    const userSchema = z.object({
    name: z.string().min(2, "名稱至少 2 個字"),
    email: z.string().email("無效的 Email"),
    age: z.number().min(18, "年齡需滿 18 歲"),
    createdAt: z.date().default(() => new Date())
    });

    // 🔹 2️⃣ User Model（封裝 Firestore 操作）
    const UserModel = {
    collection: db.collection("users"), // 指定 Firestore Collection

    // ➤ 創建 User（自動驗證欄位）
    async create(userData) {
        const parsedData = userSchema.parse(userData); // 驗證資料
        const newUserRef = await this.collection.add(parsedData);
        return { id: newUserRef.id, ...parsedData };
    },

    // ➤ 讀取單個 User
    async getById(userId) {
        const userDoc = await this.collection.doc(userId).get();
        if (!userDoc.exists) throw new Error("用戶不存在");
        return { id: userDoc.id, ...userDoc.data() };
    },

    // ➤ 更新 User（允許部分更新）
    async update(userId, updateData) {
        await this.collection.doc(userId).update(updateData);
        return { id: userId, ...updateData };
    },

    // ➤ 刪除 User
    async delete(userId) {
        await this.collection.doc(userId).delete();
        return { id: userId, deleted: true };
    }
    };

    module.exports = UserModel;
    ```

    ---

    ### 📌 **如何使用 Firestore Model**
    **📌 在 Service 層操作 Model**  
    ```javascript
    const UserModel = require("../models/userModel");

    async function registerUser(userData) {
    return await UserModel.create(userData);
    }

    async function getUserById(userId) {
    return await UserModel.getById(userId);
    }

    module.exports = { registerUser, getUserById };
    ```

    ---

    ### 📌 **這個 Model 的設計優勢**
    1️⃣ **欄位驗證** 🔍  
    - `zod` 自動驗證 `name`、`email`、`age`，防止不正確的數據進入 Firestore。  
    2️⃣ **封裝 Firestore CRUD 操作**  
    - 讓 Controller 只負責處理請求，不直接操作資料庫。  
    3️⃣ **支援預設值與錯誤處理**  
    - `createdAt` 欄位預設為當前時間，若 `getById()` 查無資料則拋出錯誤。  

    這樣的設計可以讓你的 **Node.js + Express + Firestore** 更清晰、更易維護 🚀
