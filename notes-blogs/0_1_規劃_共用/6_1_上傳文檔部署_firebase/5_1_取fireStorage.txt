小g 回答
----------------------------

要修正 `getProductImgList` 返回的图片 URL 问题，请确保以下几点：

1. **生成可访问的下载链接**：使用 Firebase Admin SDK 上传文件后，您需要生成文件的下载链接。可以通过以下方式获取：

   ```javascript
   const { getStorage } = require('firebase-admin/storage');
   const bucket = getStorage().bucket();

   // 上传文件
   const uploadFile = async (filePath, destination) => {
     await bucket.upload(filePath, { destination });
     const file = bucket.file(destination);
     const [url] = await file.getSignedUrl({
       action: 'read',
       expires: '03-09-2491', // 设置一个足够长的过期时间
     });
     return url;
   };
   ```


   上面的代码中，`getSignedUrl` 方法生成一个可公开访问的 URL。

2. **确保文件具有公共读取权限**：如果您希望文件可以被公开访问，您需要设置文件的公共读取权限。可以在上传文件后，设置文件的 ACL（访问控制列表）：

   ```javascript
   const { getStorage } = require('firebase-admin/storage');
   const bucket = getStorage().bucket();

   // 上传文件并设置公共读取权限
   const uploadFile = async (filePath, destination) => {
     await bucket.upload(filePath, { destination });
     const file = bucket.file(destination);
     await file.makePublic();
     return file.publicUrl();
   };
   ```


   `makePublic` 方法将文件设置为公开可读，`publicUrl` 方法返回文件的公开 URL。

3. **在 `getProductImgList` 中返回正确的 URL**：在您的 `getProductImgList` 方法中，确保返回的 URL 是上述方法生成的可访问链接。

   ```javascript
   const getProductImgList = async (productId) => {
     if (!productId) throw new Error('缺少 productId');
     
     const [files] = await bucket.getFiles({ prefix: `${productId}/` });
     return files.map(file => ({
       productId,
       storageName: file.name,
       imgUrl: file.publicUrl(), // 或者使用 getSignedUrl 方法获取
     }));
   };
   ```


请注意，使用 `makePublic` 方法会使文件公开可读，适用于无需保护的公共资源。如果您的文件需要访问控制，建议使用 `getSignedUrl` 方法生成带有过期时间的访问链接。

通过以上调整，`getProductImgList` 方法应能返回正确的图片 URL，确保前端能够正确显示图片。
