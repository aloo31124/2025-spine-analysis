utils/logger.js 匯出時檔名補上 伺服器日期


===============================================================================
--------------------

為了讓 `utils/logger.js` 在匯出時使用伺服器日期來命名日誌檔案，你可以將檔案名稱動態地根據當前的日期生成。這樣可以每天生成一個新的日誌檔案，方便管理和查看每一天的日誌。

以下是如何根據伺服器日期命名日誌檔案的實現方法：

### **修改 `utils/logger.js` 來根據日期命名日誌檔案**

```javascript
// src/utils/logger.js
const fs = require('fs');
const path = require('path');

// 取得當前日期並格式化成 YYYY-MM-DD
const getCurrentDate = () => {
    const date = new Date();
    const year = date.getFullYear();
    const month = String(date.getMonth() + 1).padStart(2, '0'); // 月份需要補零
    const day = String(date.getDate()).padStart(2, '0'); // 日期也需要補零
    return `${year}-${month}-${day}`; // 格式: 2025-02-16
};

// 設定 log 檔案的名稱，根據當前日期
const logFilePath = path.join(__dirname, `../../logs/application-${getCurrentDate()}.log`); 

// 確保 logs 目錄存在
if (!fs.existsSync(path.dirname(logFilePath))) {
    fs.mkdirSync(path.dirname(logFilePath), { recursive: true });
}

// 創建一個寫入日誌的函式
const logToFile = (message) => {
    const timestamp = new Date().toISOString();
    fs.appendFileSync(logFilePath, `[${timestamp}] ${message}\n`, 'utf8');
};

// 重寫 console.log 和 console.error
const originalLog = console.log;
const originalError = console.error;

// 重定義 console.log
console.log = (...args) => {
    const message = args.map(arg => (typeof arg === 'object' ? JSON.stringify(arg) : arg)).join(' ');
    logToFile(`LOG: ${message}`);  // 寫入檔案
    originalLog(...args);  // 保留原本的 console.log 行為
};

// 重定義 console.error
console.error = (...args) => {
    const message = args.map(arg => (typeof arg === 'object' ? JSON.stringify(arg) : arg)).join(' ');
    logToFile(`ERROR: ${message}`);  // 寫入檔案
    originalError(...args);  // 保留原本的 console.error 行為
};

// 匯出日誌功能
module.exports = { logToFile };
```

### **修改說明：**
1. **`getCurrentDate` 函數**：
    - 用來獲取當前日期並格式化成 `YYYY-MM-DD` 格式（例如：`2025-02-16`）。
    
2. **`logFilePath`**：
    - 動態生成日誌檔案名稱，每日一個新檔案。檔案名稱會是 `application-YYYY-MM-DD.log`，例如：`application-2025-02-16.log`。

3. **確保目錄存在**：
    - 如果 `logs` 目錄不存在，則會自動創建它。

4. **重寫 `console.log` 和 `console.error`**：
    - 在每次執行 `console.log` 或 `console.error` 時，會將輸出記錄到當日的日誌檔案中。

### **檢查日誌檔案**

當應用啟動並運行時，`logs` 目錄下會根據當前日期創建一個新的日誌檔案。例如，今天是 `2025-02-16`，那麼會生成一個名為 `application-2025-02-16.log` 的檔案，並將所有 `console.log` 和 `console.error` 的輸出寫入這個檔案中。

**範例內容（`logs/application-2025-02-16.log`）**：
```
[2025-02-16T10:00:00.000Z] LOG: 伺服器正在運行在 http://localhost:3000
[2025-02-16T10:01:00.000Z] ERROR: 伺服器發生錯誤: 無法連接到資料庫
```

### **總結：**
- 每一天的日誌將會存儲在名為 `application-YYYY-MM-DD.log` 的檔案中，這樣便於按日期查看和管理日誌。
- 這樣的處理方式使得日誌更加有組織，便於進行錯誤排查和日常運維管理。
