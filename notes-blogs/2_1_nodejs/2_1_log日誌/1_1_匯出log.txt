要實現將全域的 `console.log` 和 `console.error` 輸出匯入到指定的 `.txt` 檔案中，你可以透過以下步驟來實現。

### **步驟概述：**
1. 在 `utils` 目錄中新增一個 `logger.js` 檔案，負責處理 `console` 輸出並將其寫入檔案。
2. 在 `index.js` 或全域的入口檔案中，載入並替換 `console.log` 和 `console.error`。
3. 透過 Node.js 的 `fs` 模組來寫入 `.txt` 檔案。

### **實作步驟：**

#### **1. 在 `utils/logger.js` 中創建 Logger 功能**

這個檔案會將 `console.log` 和 `console.error` 輸出重定向到 `.txt` 檔案中，並同時保留其原始輸出。

```javascript
// src/utils/logger.js
const fs = require('fs');
const path = require('path');

// 設定 log 檔案位置
const logFilePath = path.join(__dirname, '../../logs/application.log'); // 確保 logs 目錄存在

// 創建一個寫入日誌的函式
const logToFile = (message) => {
    const timestamp = new Date().toISOString();
    fs.appendFileSync(logFilePath, `[${timestamp}] ${message}\n`, 'utf8');
};

// 重寫 console.log 和 console.error
const originalLog = console.log;
const originalError = console.error;

// 重定義 console.log
console.log = (...args) => {
    const message = args.map(arg => (typeof arg === 'object' ? JSON.stringify(arg) : arg)).join(' ');
    logToFile(`LOG: ${message}`);  // 寫入檔案
    originalLog(...args);  // 保留原本的 console.log 行為
};

// 重定義 console.error
console.error = (...args) => {
    const message = args.map(arg => (typeof arg === 'object' ? JSON.stringify(arg) : arg)).join(' ');
    logToFile(`ERROR: ${message}`);  // 寫入檔案
    originalError(...args);  // 保留原本的 console.error 行為
};

// 匯出日誌功能
module.exports = { logToFile };
```

#### **2. 確保有 `logs` 目錄**

確保你的專案根目錄有一個 `logs` 目錄，這樣可以儲存 `application.log` 檔案。

```bash
mkdir logs
```

#### **3. 在 `index.js` 或其他主檔案中載入 `logger.js`**

將 `logger.js` 引入專案中的主檔案（例如 `index.js`），這樣全域的 `console.log` 和 `console.error` 就會被重定向。

```javascript
// src/index.js 或其他主入口檔案
require('./utils/logger');  // 引入 logger.js，這樣就會覆蓋全域的 console.log 和 console.error
```

#### **4. 完整範例：**

這樣的結構會確保你在專案的任何地方使用 `console.log` 和 `console.error` 時，輸出會同時顯示在終端並寫入到 `logs/application.log` 檔案中。

```javascript
// src/index.js
const express = require('express');
const app = express();

// 引入自訂的 logger
require('./utils/logger');  // 當應用啟動時，logger 就會生效

app.get('/', (req, res) => {
    console.log('這是來自首頁的 log 輸出');
    console.error('這是來自首頁的錯誤輸出');
    res.send('Hello World');
});

app.listen(3000, () => {
    console.log('伺服器正在運行在 http://localhost:3000');
});
```

#### **5. 檢查日誌檔案**

當你啟動伺服器並在終端中訪問應用時，`console.log` 和 `console.error` 的輸出將會顯示在終端中並寫入到 `logs/application.log` 檔案中。

**`logs/application.log` 的範例內容**：

```
[2025-02-16T00:00:00.000Z] LOG: 這是來自首頁的 log 輸出
[2025-02-16T00:00:00.000Z] ERROR: 這是來自首頁的錯誤輸出
[2025-02-16T00:00:00.000Z] LOG: 伺服器正在運行在 http://localhost:3000
```

### **總結：**
- 我們通過覆蓋全域的 `console.log` 和 `console.error`，將它們的輸出記錄到指定的 `.txt` 檔案中（在這個例子中是 `application.log`）。
- 這樣可以讓你有效地記錄並持久化伺服器的日誌，以便後續分析或錯誤排查。
