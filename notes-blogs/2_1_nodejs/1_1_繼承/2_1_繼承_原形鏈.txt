**🎯 使用 JavaScript 原型鏈 (Prototype) 非 `class` 語法，抽離並繼承錯誤處理邏輯**  

以下程式碼完全使用 **原生原型 (Prototype)**，不使用 `class` 語法糖，將 `errorHandler` 抽離，讓所有 `Controller` 與 `Service` 自動繼承錯誤保護機制。

---

### **1️⃣ 建立原型錯誤處理模組**  
**`newshop-server/src/utils/baseHandler.js`**  
```javascript
function BaseHandler() {}

BaseHandler.prototype.safeExecute = async function (fn, ...args) {
    try {
        return await fn.apply(this, args);
    } catch (error) {
        console.error(`❌ [${this.constructor.name}] 執行錯誤: ${error.message}`);
        console.error(error.stack);
        return null; // 可根據需求調整返回值
    }
};

module.exports = BaseHandler;
```

---

### **2️⃣ 改造 `Controller` 使用原型繼承**
**`newshop-server/src/controllers/manager/product.api.controller.js`**
```javascript
const BaseHandler = require('../../utils/baseHandler');
const productService = require('../../services/product.service');

function ProductController() {}
ProductController.prototype = Object.create(BaseHandler.prototype);

ProductController.prototype.getProductList = async function (req, res) {
    const productList = await this.safeExecute(productService.getProductList);
    res.status(200).json({
        result: productList ? '200' : '500',
        productList,
    });
};

module.exports = new ProductController();
```

---

### **3️⃣ 改造 `Service` 使用原型繼承**
**`newshop-server/src/services/product.service.js`**
```javascript
const db = require('../firestore');

const BaseHandler = require('../utils/baseHandler');
function ProductService() {}
ProductService.prototype = Object.create(BaseHandler.prototype);

ProductService.prototype.getProductList = async function () {
    const snapshot = await db.collection('Product').get();
    return snapshot.docs.map(doc => ({
        id: doc.id,
        ...doc.data(),
    }));
};

module.exports = new ProductService();
```

---

### **4️⃣ 設定 Express 路由**
**`newshop-server/src/index.js`**
```javascript
const express = require('express');
const productController = require('./controllers/manager/product.api.controller');

const app = express();
app.use(express.json());

app.get('/api/manager/product/list', (req, res) => productController.getProductList(req, res));

const PORT = 3000;
app.listen(PORT, () => {
    console.log(`🚀 Server is running on http://localhost:${PORT}`);
});
```

---

### 💡 **運作說明**
- ✅ **使用原生 Prototype 實現繼承**：無 `class`，純 JavaScript 原型鏈設計。  
- ✅ **集中管理錯誤處理**：所有繼承自 `BaseHandler` 的方法自動具備錯誤捕獲功能。  
- ✅ **維持程序不中斷**：發生例外會輸出錯誤訊息，但不會終止整個應用程式。  
- ✅ **高可重用性**：`safeExecute()` 可用於任意異步方法。

### 💎 **結語**
- **簡潔原生寫法**：無需 `class` 語法糖，純粹原型設計，效能高且簡單直觀。  
- **高效且可維護**：`BaseHandler` 作為錯誤處理核心，可擴充更多通用功能。  
- **完善的錯誤追蹤**：每個報錯皆附上元件名稱，方便除錯。
