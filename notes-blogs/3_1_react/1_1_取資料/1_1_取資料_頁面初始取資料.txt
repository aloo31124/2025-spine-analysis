請200字簡單說明 useEffect 其 [] 用途為何?
    useEffect(() => {...
    }, []);

-------------------------------------------------

    useEffect 中的空陣列 [] 代表
        effect 只會在元件 第一次渲染（mount）時執行一次。這是因為：

        useEffect 的第二個參數（依賴陣列）用來告訴 React 什麼時候需要重新執行這個 effect
        當依賴陣列是空的 [] 時，表示這個 effect 不依賴任何值的變化
        因此 React 只會在元件首次渲染時執行一次，之後即使元件重新渲染也不會再次執行

    這種用法常見於：
        初始化資料獲取（如 API 呼叫）
        訂閱外部事件
        設定初始狀態
        WebSocket 連接建立

    如果不提供依賴陣列，effect 會在每次渲染後執行；
    如果依賴陣列包含值，則當這些值改變時，effect 會重新執行。
